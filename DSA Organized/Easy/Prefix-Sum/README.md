# Prefix Sum — Easy

No current Easy submission implements the prefix sum pattern. This folder is ready for those solutions as they are added.

A prefix sum stores cumulative totals so a range sum can be computed by subtracting two prefix totals. Related prefix/suffix accumulation techniques also belong in this pattern family.

Add `Prefix-Sum` to a problem's `categories` list in [`scripts/problem_metadata.json`](../../../scripts/problem_metadata.json), keeping its existing category, to have the organizer sync its submissions here.
